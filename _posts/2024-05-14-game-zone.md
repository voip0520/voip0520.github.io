> **Máquina:** Game Zone · **Plataforma:** TryHackMe · **SO:** Linux · **Dificultad:** Media

## 1. Reconocimiento

El escaneo de puertos sobre `10.10.218.60` revela dos servicios: SSH (22) y HTTP (80).

![Escaneo de puertos con Nmap](/assets/informes/game-zone/p03_01.jpg)

El sitio web presenta un formulario de inicio de sesión.

![Página de login de Game Zone](/assets/informes/game-zone/p03_02.jpg)

Resumen del objetivo:

| Campo | Valor |
|---|---|
| IP | 10.10.218.60 |
| Sistema Operativo | Linux |
| Puertos | 22/SSH · 80/HTTP |
| Vectores | SQLi · Webmin |

## 2. Análisis de vulnerabilidades

El análisis con scripts NSE resume la superficie de ataque del servicio web.

![Reporte de análisis](/assets/informes/game-zone/p04_03.jpg)

## 3. Explotación

### Bypass de autenticación por SQLi

Se evade el login mediante una inyección SQL clásica en el campo de usuario:

```sql
' or 1=1#
```

![Bypass de login con SQLi](/assets/informes/game-zone/p05_04.jpg)

El bypass da acceso al portal interno `portal.php`, que incluye un buscador de reseñas.

![Portal interno de Game Zone](/assets/informes/game-zone/p06_05.jpg)

### Enumeración de la base de datos con SQLMap

Se captura la petición de búsqueda con Burp Suite y se guarda para procesarla con SQLMap.

![Captura de la petición con Burp](/assets/informes/game-zone/p06_06.jpg)

SQLMap confirma la inyección y enumera la base de datos.

![Enumeración con SQLMap](/assets/informes/game-zone/p07_07.jpg)

![Volcado de tablas](/assets/informes/game-zone/p07_08.jpg)

Se obtiene una tabla de usuarios con el usuario `agent47` y su contraseña cifrada.

![Credenciales extraídas](/assets/informes/game-zone/p08_09.jpg)

### Crackeo del hash

El hash se identifica como **SHA-256** y se descifra tanto con servicios online como con John the Ripper:

```bash
john hash --wordlist=/usr/share/wordlists/rockyou.txt --format=Raw-SHA256
```

![Identificación del hash](/assets/informes/game-zone/p08_10.jpg)

![Descifrado del hash](/assets/informes/game-zone/p08_11.jpg)

![Crackeo con John](/assets/informes/game-zone/p08_12.jpg)

Con la contraseña recuperada se establece acceso por SSH como `agent47`, obteniendo la primera bandera.

![Acceso SSH como agent47](/assets/informes/game-zone/p08_13.jpg)

## 4. Escalada de privilegios

La enumeración local revela un servicio **Webmin** escuchando en el puerto 10000 solo en localhost. Se crea un túnel SSH para exponerlo:

```bash
ssh -L 10000:localhost:10000 agent47@10.10.218.60
```

![Túnel SSH hacia Webmin](/assets/informes/game-zone/p09_14.jpg)

![Acceso a Webmin en localhost:10000](/assets/informes/game-zone/p09_15.jpg)

Con SearchSploit se localiza un exploit de ejecución remota de comandos para la versión de Webmin.

![Búsqueda del exploit con SearchSploit](/assets/informes/game-zone/p09_16.jpg)

Se emplea el módulo `exploit/unix/webapp/webmin_show_cgi_exec` en Metasploit, configurando las credenciales de `agent47`.

![Módulo de Webmin en Metasploit](/assets/informes/game-zone/p10_17.jpg)

![Configuración del módulo](/assets/informes/game-zone/p10_18.jpg)

Tras ajustar el payload y desactivar SSL, la explotación devuelve una sesión con privilegios de root.

![Ejecución del exploit](/assets/informes/game-zone/p10_19.jpg)

![Sesión de root obtenida](/assets/informes/game-zone/p11_20.jpg)

![Selección de la sesión root](/assets/informes/game-zone/p11_21.jpg)

![Confirmación de acceso root](/assets/informes/game-zone/p11_22.jpg)

| Usuario | Archivo | Bandera |

| root | bandera1.txt | a4b945830144bdd71908d12d902adeee |

## 6. Herramientas utilizadas

Kali Linux, Nmap, Burp Suite, SQLMap, John the Ripper, SearchSploit, Metasploit Framework y Exploit-DB.

## 7. Recomendaciones de mitigación

Parametrizar las consultas SQL para eliminar la inyección, almacenar contraseñas con algoritmos de hashing lentos y salteados, actualizar Webmin a una versión sin la vulnerabilidad de RCE y no exponer paneles de administración, ni siquiera en localhost, sin controles adicionales.
