> **Plataforma:** Guías

Manual avanzado Wazuh - Nivel SOC

Este manual cubre instalación, troubleshooting y detección de ataques reales.


## 1. Troubleshooting Dashboard


Problemas comunes:

1. Server not ready
Solución:
Editar /etc/wazuh-dashboard/opensearch_dashboards.yml
opensearch.hosts: ["https://IP:9200"]

2. Login inválido
Ejecutar:
wazuh-passwords-tool.sh --change-all

3. API Offline
Editar:
/usr/share/wazuh-dashboard/data/wazuh/config/wazuh.yml

username: wazuh
password: wazuh
      

## 2. Comandos Clave


systemctl status wazuh-dashboard
systemctl status wazuh-manager
systemctl status wazuh-indexer

ss -tulpn | egrep '443|9200|55000'

curl -k https://127.0.0.1:55000
      

## 3. Agentes


Linux:
curl -sO https://packages.wazuh.com/4.x/wazuh-agent.sh
bash wazuh-agent.sh -a

Windows:
msiexec /i wazuh-agent.msi /q WAZUH_MANAGER="IP"

Registro manual:
agent-auth.exe -m IP
      

## 4. Ataques de Prueba


Nmap:
nmap -sS IP

Hydra:
hydra -l root -P rockyou.txt ssh://IP

Windows:
net user hacker 123456 /add

Resultado:
Alertas en Security Events
      

## 5. Integración Sysmon


Descargar Sysmon:
https://learn.microsoft.com/sysinternals/downloads/sysmon

Instalar:
sysmon -i config.xml

Wazuh detecta:
- procesos
- conexiones
- persistencia
