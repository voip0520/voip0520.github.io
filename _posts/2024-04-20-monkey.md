> **Máquina:** Monkey · **Plataforma:** Hacking · **SO:** Linux · **Dificultad:** Media

## 1. Reconocimiento

El descubrimiento de hosts sitúa el objetivo en `192.168.231.138`.

![Descubrimiento de host](/assets/informes/monkey/p03_01.jpg)

El escaneo de puertos con Nmap revela servicios de correo y web: FTP (21), SMTP (25), POP3 (110), IMAP (143) y HTTPS (443).

![Escaneo de puertos](/assets/informes/monkey/p03_02.jpg)

El análisis con OpenVAS detecta acceso **FTP anónimo**, donde se localiza un archivo `notas.txt`.

![Análisis de vulnerabilidades](/assets/informes/monkey/p04_03.jpg)

![Acceso FTP anónimo](/assets/informes/monkey/p04_04.jpg)

Resumen del objetivo:

| Campo | Valor |
|---|---|
| IP | 192.168.231.138 |
| Sistema Operativo | Linux |
| Puertos | 21/FTP · 25/SMTP · 110/POP3 · 143/IMAP · 443/HTTPS |
| Vectores | FTP anónimo · file upload · cron a root |

## 2. Análisis y enumeración

La lectura de `notas.txt` revela la creación de un usuario `hackermentor` y un hash que podría corresponder a su contraseña.

![Contenido de notas.txt](/assets/informes/monkey/p05_05.jpg)

El hash se descifra con el servicio online CrackStation. A continuación se enumeran directorios web con `gobuster`:

```bash
gobuster dir -u http://192.168.231.138/ -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt
```

![Crackeo del hash y enumeración con gobuster](/assets/informes/monkey/p06_06.jpg)

![Directorios descubiertos](/assets/informes/monkey/p06_07.jpg)

Se descubre la aplicación bajo `/monkey`, con un panel de administración.

![Panel de administración](/assets/informes/monkey/p07_08.jpg)

![Enumeración de subdirectorios](/assets/informes/monkey/p07_09.jpg)

En `/monkey/db/` se descarga un archivo con un usuario y un hash adicionales, también crackeados con CrackStation, que permiten acceder al panel de administración.

![Recursos en /assets](/assets/informes/monkey/p08_10.jpg)

![Archivo en /db](/assets/informes/monkey/p08_11.jpg)

![Acceso al panel de administración](/assets/informes/monkey/p08_12.jpg)

## 3. Explotación

## 4. Escalada de privilegios

Se transfiere `linpeas.sh` y se ejecuta tras darle permisos:

```bash
chmod +x linpeas.sh
./linpeas.sh
```

![Ejecución de linpeas](/assets/informes/monkey/p12_19.jpg)

La auditoría revela una contraseña en texto claro, posiblemente de la base de datos.

![Contraseña expuesta en texto claro](/assets/informes/monkey/p13_20.jpg)

Con `crackmapexec` se valida que la credencial da acceso por SSH como `hackermentor`.

![Validación con crackmapexec](/assets/informes/monkey/p13_21.jpg)

![Acceso SSH como hackermentor](/assets/informes/monkey/p14_22.jpg)

linpeas también reveló un script de backup ejecutado periódicamente **como root** (tarea programada), ubicado en el perfil de `hackermentor`. Se inyecta código malicioso en dicho script:

![Script de backup ejecutado como root](/assets/informes/monkey/p14_23.jpg)

![Inyección de código en el script](/assets/informes/monkey/p14_24.jpg)

Con un listener en el puerto 4433, al ejecutarse la tarea se obtiene una shell como superusuario.

![Preparación del listener](/assets/informes/monkey/p15_25.jpg)

![Acceso como root](/assets/informes/monkey/p15_26.jpg)

De forma adicional, la contraseña recuperada también da acceso al panel de **phpMyAdmin**.

![Acceso a phpMyAdmin](/assets/informes/monkey/p15_27.jpg)

![Panel de phpMyAdmin](/assets/informes/monkey/p16_28.jpg)

## 6. Herramientas utilizadas

Kali Linux, Nmap, OpenVAS, gobuster, CrackStation, revshells.com, linpeas.sh, crackmapexec y phpMyAdmin.

## 7. Recomendaciones de mitigación

Deshabilitar el acceso FTP anónimo, validar de forma estricta el tipo y la extensión de los archivos subidos, evitar el almacenamiento de credenciales en archivos accesibles y en texto claro, y restringir los permisos de las tareas programadas ejecutadas como root.
